Auto-Sync 1 Jam

Seluruh parameter kualitas udara dan cuaca untuk area Sukabumi, Kalimantan, dan Depok diambil secara berkala setiap 1 jam dan disimpan ke dalam database relasional MySQL (air_quality) menggunakan layanan API terbuka berikut:

Open-Meteo Air Quality API
Menyediakan data konsentrasi partikel halus (PM2.5) serta indeks kualitas udara standar Amerika Serikat (US AQI) per jam.
https://open-meteo.com/en/docs/air-quality-api ↗
Open-Meteo Weather Forecast API
Menyediakan data meteorologi lokal mencakup suhu udara (°C) dan kelembapan relatif (%) berdasarkan koordinat wilayah.
https://open-meteo.com/en/docs ↗
